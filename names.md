# Possible App Names

Alternative names for the KMCounter project, focusing on the app's purpose: tracking keyboard/mouse activity and visualizing usage patterns via heatmaps.

## Short & Punchy
- **KeyTrack** — tracks keystrokes + mouse
- **TapStats** — focuses on the counting aspect
- **HeatKeys** — references the heatmap
- **KeyMeter** — measures key activity
- **TypePulse** — pulse of your typing
- **KeyFlow** — flow of input activity
- **InputViz** — input visualization
- **KeyLens** — looking through a lens at your keys

## Descriptive
- **StrokeCount** — straightforward keystroke counter
- **KeyLog** — a log/tally of key activity
- **InputScope** — broad view of all input
- **DesktopDashboard** — desktop activity dashboard
- **Keystat** — key + statistics
- **TypeTally** — typing tally counter
- **DigitTally** — digital tally counter

## Playful / Brandable
- **BoardBeat** — heartbeat of your keyboard
- **PulseKey** — like a pulse for keyboard/mouse
- **DeskPulse** — desktop activity pulse
- **ActiType** — activity + type
- **PressPlay** — press keys, play stats
- **KeySense** — sense your keyboard activity
- **InputIQ** — input intelligence
- **BoardTrack** — board + track

## Technical / Neutral
- **HIDScope** — Human Interface Device scope
- **PeriStat** — peripheral statistics
- **TypeWatch** — monitoring typing activity
- **ClickTrack** — click tracking
- **InputMeter** — input measurement tool

*Current name: KMCounter (Key Mouse Counter)*
